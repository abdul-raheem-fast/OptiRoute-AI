05 How the cascade works

No live model calls are needed to decide — the router is a small trained scorer that runs before any dispatch.

a

Score, don’t ask

From the query text alone — hashed n-gram features, text stats, capability class — a per-model head estimates P(correct) for all eight models. Milliseconds, zero tokens spent.

b

Walk cheapest-first

Models are tried in ascending cost order. The first one whose P(correct) clears the threshold t = 0.95 gets the query. Confidence is the gate; cost is the ordering.

c

Escalate when unsure

If no model clears the bar, the query falls back to the strongest model — the safety valve that keeps quality at 94.8% of always-GPT-5 while cutting cost 68.4%.
